# Stonks Leaderboard Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship `/stonks` as a ranked, mobile-first desk board of eight Sep 2 2026 $400 fills, with since-buy P/L, sparklines, and one-at-a-time expanded charts.

**Architecture:** Hardcoded lots in `data/stonks.json`. Pure math in `lib/stonks/math.js`. Yahoo chart API behind `lib/stonks/yahoo.js`, exposed only via `/api/stonks/quotes` and `/api/stonks/history`. The page ranks on the client, polls quotes every 30s while visible, and isolates styles so global Comic Sans / GIF chrome does not leak.

**Tech Stack:** Next.js Pages Router 15, React 18, CSS modules, `node:test`, SVG charts (no chart library), Yahoo `v8/finance/chart` (server-only).

## Global Constraints

- Rank by overall `%` vs fill; ties keep `data/stonks.json` order.
- Overall `$` = `(last × shares) − 400`; overall `%` = `(last − fill) / fill`.
- Today `$` = `(last − previousClose) × shares`; today `%` = `(last − previousClose) / previousClose`.
- History window starts `2026-09-02T13:30:00.000Z` (09:30 America/New_York).
- Sparkline interval: `5m` if ≤5 calendar days, else `1d`. Expanded: `5m` ≤5 days, `1h` ≤30 days, else `1d`.
- One expanded card at a time. Green/red only on signed P/L and matching charts.
- No new npm dependencies. Browser never calls Yahoo.
- Visual: IBM Plex Sans + IBM Plex Mono, warm paper `#f3f0ea`, graphite type, hairline rules, radius ≤4px.

```js
const { describe, it } = require("node:test");
const assert = require("node:assert/strict");
const {
  overallPnL,
  todayPnL,
  portfolioDollars,
  rankPositions,
  nextExpandedId,
  historyInterval,
} = require("./math");

describe("overallPnL", () => {
  it("uses last vs fill and $400 cost", () => {
    const r = overallPnL({ last: 26.36, fill: 24.36, shares: 16.420833 });
    assert.equal(Number(r.dollars.toFixed(2)), 32.84);
    assert.equal(Number(r.percent.toFixed(4)), 0.0821);
  });
});

describe("todayPnL", () => {
  it("uses last vs previous close times shares", () => {
    const r = todayPnL({ last: 26.36, previousClose: 25.00, shares: 16.420833 });
    assert.equal(Number(r.dollars.toFixed(2)), 22.33);
    assert.equal(Number(r.percent.toFixed(4)), 0.0544);
  });
});

describe("rankPositions", () => {
  it("sorts by overall percent desc and keeps file order on ties", () => {
    const rows = [
      { ticker: "AAA", fileIndex: 0, overall: { percent: 0.1, dollars: 10 } },
      { ticker: "BBB", fileIndex: 1, overall: { percent: 0.2, dollars: 20 } },
      { ticker: "CCC", fileIndex: 2, overall: { percent: 0.1, dollars: 10 } },
    ];
    const ranked = rankPositions(rows);
    assert.deepEqual(ranked.map((r) => r.ticker), ["BBB", "AAA", "CCC"]);
    assert.deepEqual(ranked.map((r) => r.rank), [1, 2, 3]);
  });
});

describe("portfolioDollars", () => {
  it("sums overall dollars", () => {
    assert.equal(
      portfolioDollars([
        { overall: { dollars: 10 } },
        { overall: { dollars: -3.5 } },
      ]),
      6.5
    );
  });
});

describe("nextExpandedId", () => {
  it("opens, closes, and switches", () => {
    assert.equal(nextExpandedId(null, "A"), "A");
    assert.equal(nextExpandedId("A", "A"), null);
    assert.equal(nextExpandedId("A", "B"), "B");
  });
});

describe("historyInterval", () => {
  it("picks sparkline and detail intervals", () => {
    assert.equal(historyInterval(1, 0), "5m");
    assert.equal(historyInterval(6, 0), "1d");
    assert.equal(historyInterval(5, 1), "5m");
    assert.equal(historyInterval(6, 1), "1h");
    assert.equal(historyInterval(31, 1), "1d");
  });
});
```

### Task 3: Yahoo adapter + API routes

**Files:**
- Create: `lib/stonks/yahoo.js`
- Create: `pages/api/stonks/quotes.js`
- Create: `pages/api/stonks/history.js`

**Interfaces:**
- Consumes: `historyInterval`, `PURCHASED_AT` from math.js (or duplicate the timestamp from JSON)
- Produces:
  - `fetchChart(ticker, { interval, period1, period2 })` → parsed Yahoo `chart.result[0]`
  - `quoteFromChart(result)` → `{ ticker, last, previousClose, open, high, low, quoteTime }` (`quoteTime` ISO string). Missing fields → throw.
  - `pointsFromChart(result)` → `{ t: number, close: number }[]` dropping null closes
  - Quotes handler: `{ quotes: Quote[], fetchedAt }` — Promise.allSettled per ticker; rejected tickers omitted (page marks stale)
  - History handler: query `ticker` (must be one of the eight), `detail` `0|1`. `{ ticker, interval, points }`. 400 if bad ticker.

Yahoo URL: `https://query1.finance.yahoo.com/v8/finance/chart/${ticker}?interval=${interval}&period1=${period1}&period2=${period2}&includePrePost=false`

Send `User-Agent: Mozilla/5.0` (Yahoo rejects default Node UA). Use global `fetch` (Next 15). Timeout 8s.

Quotes: `interval=1d`, `period1` = purchasedAt unix, `period2` = now. Read `meta.regularMarketPrice`, `meta.chartPreviousClose` or `meta.previousClose`, `meta.regularMarketDayHigh`, `meta.regularMarketDayLow`, `meta.regularMarketOpen` or first valid open in indicators, `meta.regularMarketTime`.
